# Pemilih Muda PWA Icons

Ikon produksi dibuat khusus untuk Pemilih Muda dengan monogram PM, ballot/checkmark netral, navy `#123b6d`, teal `#19789c`, dan aksen emas. Source raster disimpan sebagai `icon-source-2048.png`; seluruh ukuran launcher diturunkan menggunakan high-quality bicubic resize.

Maskable icon memakai komposisi bersafe-area besar agar emblem tidak terpotong oleh lingkaran, squircle, atau adaptive mask Android. `apple-touch-icon.png` berukuran 180×180.

Prompt final menggunakan built-in image generation: launcher icon government digital service, monogram PM dan ballot/checkmark netral, opaque navy background, white/teal/gold, square, legible pada 72px, minimum 22% safe area, tanpa logo lembaga/partai/kandidat atau watermark.
